1. 检测区内禁止饮食、化妆和存放个人物品，禁止私拉电线与插线板串联。
2. 进入分子检测室、微生物检测室前按分区更衣，穿戴实验服和手套；有喷溅风险时佩戴口罩和护目镜。
3. 样本、培养物、检测废弃物不得带出检测室，按医疗废物分类收集，交给指定人员转运。
4. 不熟悉的仪器不要擅自开机。生物安全柜运行期间不要关闭风机，柜内不要使用明火。
5. 高效液相色谱、气质联用的流动相和废液按化学品制度收集，不要倒入普通下水道。
6. 发生样本泼洒、仪器冒烟、异响或异常气味：停止操作、保护现场并立即通知管理员，不要自行处理不明化学品。
7. 最后离开者负责关闭仪器至待机、关灯、锁门，并确认废弃物已入指定容器。
