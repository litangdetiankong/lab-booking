1. 开放时间：理化检测室、免疫检测室为工作日 09:00-21:00；分子检测室、微生物检测室为工作日 09:00-18:00。周末不开放。「维护中」的检测室暂停预约。
2. 管理员职责：预约审核、仪器维护、生物安全巡查、违规登记和报修跟进。
3. 违规包括在检测区饮食、未按要求更衣进入洁净区、私自带出样本或培养物、带领未授权人员进入。首次警告，累计三次暂停使用资格。
4. 精密仪器实行使用登记：用前登记、用后销记，并核对质控是否在控。
5. 每月最后一个工作日进行生物安全检查、试剂效期核对和仪器盘点。
6. 检测室当前设置：分子检测室（检验楼 3 层 301）、微生物检测室（检验楼 3 层 302）、理化检测室（检验楼 2 层 201）、免疫检测室（检验楼 2 层 202）、样本前处理室（检验楼 1 层 105，维护中）。
